# 工程平台前端原型 v0.6

纯静态、无依赖，直接打开 `index.html` 即可。用于确认信息架构、页面形态与关键交互，确认后再翻译成 Vue3 + Element Plus。

## 信息架构（4 个菜单）

| 菜单 | 职责 |
|---|---|
| 需求管理 | 只看我创建或与我相关的需求；弹窗内创建/绑定分支 |
| 后端部署 | api 服务：项目、环境、已部署/待部署分支、确认部署、实时进度、Pod 状态 |
| 前端部署 | 与后端完全同构，只换 web 服务 |
| 审批待办 | test 首次部署的 CR 审批，表格 + 搜索/服务筛选 |

## 部署页

- 标题行：`后端部署` + 项目下拉框；不再显示描述文字
- 环境切换：44px 圆球内写 dev/test/uat/prod，圆球间用细线连接，已走过线段和当前环境为蓝色；切换有 420ms 加载动画
- **已部署分支**列：需求（编号+标题同行）/ 分支 / 部署提交 / 部署时间 / 标签 / 部署结果
  - 标签列：`已CR`、`待CR`、`未CR`、`有新提交`、`部署中`
  - 有失败分支时，卡片标题栏右侧出现蓝色「重试」，一次重试该环境全部失败分支（不满足门禁的自动跳过）
  - 部署结果列在最右：只显示 `成功 / 失败 / 部署中 / 合并冲突`
  - `有新提交` 可点 → 「确认部署」→ 确认后开始；已有部署进行中则提示不能部署
  - 合并冲突：结果列显示 `合并冲突` + 「已解决」文字链接；本地解决冲突并推送后点「已解决」，直接进入重新部署确认
- **待部署分支**列：勾选一个或多个 → 「部署选中」同样先弹确认
- **部署进度**：仅在有部署时出现；开始时间 + 5 张流程卡片固定一行，单步约 2 秒；完成态卡片为白底，只用绿色勾表示成功，避免整片绿色
  - 运行中提供「终止部署」按钮（进度卡片右上与标签列各一个），点击后当前步骤置失败、环境回到可部署，不再保留成功横幅，只弹 toast
- **Pod 状态**：底部单行长条（Pod 名、状态、就绪/存活/节点），日志 / YAML 弹窗；镜像与重启次数收进 YAML
- **生产环境专属**：额外显示「生产版本与回滚」卡片，列出当前线上版本与上一版本，可回滚；回滚走同样的发布流程并交换版本记录

## 需求管理

- 只显示 `owner = 当前用户` 或 `related` 包含当前用户的需求
- 点击需求开弹窗，不跳页
- 创建分支：只填后缀，自动拼当天日期，例如 `bugfix-ledger` → `20261113-bugfix-ledger`，输入时实时预览
- 也可绑定已有分支；绑定后才出现在部署页

## 审批待办

- 标准表格 + 搜索框 + 服务筛选（全部 / 后端 / 前端）
- 开发视角按钮禁用；CR 管理员可驳回/通过

## 弹窗

- 需求弹窗、CR 弹窗、确认部署弹窗、日志/YAML 弹窗：头尾固定、内容滚动
- 关闭方式：右上角 ×、底部按钮、点遮罩、Esc

## 演示要点

1. **角色过滤**：开发 6 条需求；CR 管理员只剩 REQ-001。
2. **分支命名**：REQ-006 填 `budget-check` → 生成 `20261113-budget-check`。
3. **CR 标签**：test 环境 `已CR` 只读；`待CR / 未CR / CR驳回` 可点开指定人员弹窗。
4. **有新提交**：切到 uat，REQ-002 显示 有新提交；点击 → 确认部署 → 开始进度；部署中再次点击会被拒绝。
5. **合并冲突**：uat 的 REQ-004 显示 `合并冲突` + 「已解决」；点击后直接弹重新部署确认。
6. **重试**：dev 的 REQ-005 失败，「已部署分支」标题栏右侧出现蓝色「重试」；点击进入确认部署，重试全部失败分支。
7. **终止部署**：任一次部署开始后，进度卡片和该行标签都出现「终止部署」；点击后状态变「部署已终止」，环境回到可部署，无成功横幅。
8. **生产回滚**：切到 prod，REQ-002 有「生产版本与回滚」卡片，回滚后当前/上一版本互换并提示成功。
9. **Pod**：部署页底部 Pod 长条卡片，日志/YAML 可弹窗查看。
10. **切换动画**：环境/项目切换有加载态；无部署时不显示空进度行。

## 设计约定

- 整站浅色，Element UI 风格：白色侧栏 + `#F5F7FA` 内容区，卡片 12px 圆角、控件 10px、状态标签胶囊形，轻阴影
- 英文与数字优先 Segoe UI，中文优先 MiSans；仅代码与 SHA 用等宽字体
- 主色 `#409EFF`，成功 `#67C23A`、警告 `#E6A23C`、失败 `#F56C6C`；文字 `#303133 / #606266 / #909399`
- 环境切换：`dev / test / uat / prod` 四个圆球，当前环境蓝底白字
- 分支、SHA、镜像、Pod 名用等宽字体；状态标签为 Element 风格浅底描边
- 所有时间、SHA、人名、Pod 信息均为演示数据
